# visual-rabbit-hole

a claude code skill that explains any concept like you're talking to a curious friend with a whiteboard.

analogies that actually hit. ascii diagrams. the gotcha everyone misses. and a rabbit hole of "wait, what's *that*?" to keep you going.

works for anything — physics, philosophy, finance, code, whatever you're trying to wrap your head around.

## install

```bash
git clone https://github.com/albertbethlowsky/visual-rabbit-hole.git ~/.claude/skills/visual-rabbit-hole
```

that's it. claude code picks it up automatically.

## use

just ask claude to explain something:

- "explain recursion"
- "what is inflation"
- "how does mRNA work"
- "break down monads for me"

it searches the web when it needs real-world examples or current info.

## contributing

PRs are open. you're welcome to contribute.

but be real with yourself before you open one: if it changes core ideas or isn't well thought through, it's getting closed. think it through, make it sharp, then submit.
